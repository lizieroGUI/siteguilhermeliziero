# Lume Terapia — demonstração de portfólio

Página conceitual de cuidado emocional criada para o portfólio de Guilherme Liziero. Referência visual: https://www.behance.net/gallery/254463061/Mental-Health-Therapy-Website-UIUX-Design.

Marca, profissional, contatos, endereço, depoimento, títulos de artigos e serviços são fictícios. Nenhum botão faz agendamento ou envia dados.

As sete fotografias em `img/` foram geradas para esta demonstração e convertidas em WebP.
